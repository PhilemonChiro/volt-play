# Security

Please report security problems privately, not in a public issue:

- on GitHub, use **Report a vulnerability** on this repository's Security tab, or
- email licensing@voltembedded.com with "Security" in the subject.

Include what you found, how to reproduce it, and the version (Volt IDE: bottom-right of the window; CLI: `volt version`).
You'll get a reply within a few days. Please give us a chance to ship a fix before disclosing it publicly.

Fixes go into the latest release only: Volt IDE updates itself, and `volt` updates with the installer.
